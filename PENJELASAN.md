
# Penjelasan Singkat Program

Program iki yaiku website forum mahasiswa sederhana kanggo Fakultas Ilmu Komputer Kelas A Angkatan 2025.

Website iki nduweni:
- Dashboard
- Jadwal kuliah
- Pengumuman
- Forum diskusi mahasiswa

Tampilan dibuat mirip dashboard kampus modern kaya MyITS:
- Sidebar kiri
- Konten utama di kanan
- Tombol menu rapi
- Warna biru akademik

# Penjelasan Kode Baris demi Baris

## HTML
- `div sidebar` = menu sebelah kiri
- `button onclick` = tombol pindah halaman
- `table` = menampilkan jadwal
- `textarea` = tempat menulis forum

## CSS
- `display:flex` = membagi sidebar dan konten
- `border-radius` = membuat sudut membulat
- `background` = memberi warna

## JavaScript
- `tampilHalaman()` = ganti tampilan halaman
- `kirimForum()` = mengirim pesan forum
- `localStorage` = menyimpan data forum di browser
