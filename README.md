
# Forum Mahasiswa Fasilkom 2025

Program iki cocog kanggo pemula sing lagi sinau HTML, CSS, lan JavaScript.

## Fitur
- Dashboard mahasiswa
- Jadwal kuliah
- Pengumuman
- Forum diskusi mahasiswa
- Penyimpanan data sederhana nganggo localStorage

## Aplikasi sing dibutuhake
1. Visual Studio Code
2. Browser Google Chrome
3. Extension Live Server

## Cara Menjalankan
1. Buka folder project
2. Klik kanan file index.html
3. Pilih Open with Live Server

## Cara Deploy ke Vercel
1. Upload project ke GitHub
2. Login Vercel
3. Import repository GitHub
4. Klik Deploy

## Catatan Database
Versi iki nggunakake localStorage supaya gampang kanggo pemula.
Yen pengin database asli, file SQL wis disiapke ing folder database.
